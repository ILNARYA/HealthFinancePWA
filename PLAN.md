# PLAN.md — «Здоровье и Медицинские Финансы 2-в-1» PWA

## Визуальная концепция (строго по референсам `healthcare_1.webp` и `healthcare_2.png`)
- **Цветовая палитра:** фирменный фиолетовый градиент (`#7C3AED` → `#A855F7` → `#C084FC` → `#E9D5FF`), белоснежные карточки `rounded-3xl` с мягкими тенями, тёмные контрастные акценты (`#0F172A`).
- **Типографика:** крупные числовые показатели (`font-black text-5xl/6xl`, запятая в `88,2`), аккуратные единицы измерения и подписи.
- **Score Breakdown (по `healthcare_2.png`):**
  - Шестиугольный паутинный график (Radar chart) по 6 осям: Калории, ИМТ (BMI), Пульс (BPM), Гидратация, Сон, Шаги.
  - Наложение 3 полупрозрачных слоев: Wellness (зелёный/изумруд), Сон (графитовый/slate), Выносливость (насыщенный фиолетовый).
  - Крупный общий индекс **88,2** + подпись «Отличное состояние здоровья».
  - Сегментный переключатель периодов: `1d`, `1w`, `1m`, `1y`, `All`.
- **Карточки биомаркеров (по `healthcare_1.webp`):**
  - Название, дата взятия анализа, иконка колбы `FlaskConical`.
  - Крупное значение + единица измерения + статус («В норме», «Ниже нормы», «Выше нормы»).
  - Горизонтальный трек диапазона с цветной точкой-индикатором и подсветкой нормального коридора.
  - Пояснение статуса («Показатель в пределах целевой нормы»).
- **График динамики диапазона показателей (по `healthcare_1.webp`):**
  - Карточка электролитов: `4.2 – 4.6 ммоль/л`, стабильный диапазон за 6 месяцев.
  - Интерактивные парящие вертикальные столбики (диапазоны min-max) с темным тултипом `4.2 – 4.6`.

## Архитектура проекта

```
src/
├── main.tsx
├── App.tsx                    # Нативный мобильный shell 390px с iOS Status Bar
├── index.css                  # Tailwind CSS + градиенты + шрифты
├── vite-env.d.ts
├── components/
│   ├── layout/
│   │   └── BottomNav.tsx      # Нижняя навигационная панель (4 вкладки + Home Indicator)
│   └── dashboard/
│       ├── HealthIndex.tsx    # Радар-график + крупный score 88,2 (healthcare_2.png)
│       ├── PeriodSelector.tsx # Сегментный переключатель 1d / 1w / 1m / 1y / All
│       ├── BiomarkerCard.tsx  # Карточка показателя с горизонтальным слайдером нормы
│       ├── BiomarkerRangeChart.tsx # Плавающие столбики диапазонов (healthcare_1.webp)
│       └── SpendingSummary.tsx # Градиентная карточка мед. трат за месяц
├── pages/
│   ├── DashboardPage.tsx      # Дашборд: здоровье + траты + ключевые биомаркеры + тренд
│   ├── AnalysesPage.tsx       # Загрузка анализов + OCR/AI разбор + дисклеймер
│   ├── FinancesPage.tsx       # Финансы + донат-чарт + врачи + форма добавления расхода
│   └── SettingsPage.tsx       # Google Таблицы/Диск/Фото + Экспорт/Импорт JSON + PWA статус
├── data/
│   └── demo.ts                # Реалистичные демо-данные (биомаркеры, врачи, траты)
├── types/
│   └── index.ts               # Строгая TypeScript типизация
└── utils/
    └── analysisEngine.ts      # Движок имитации ИИ-анализа лабораторных бланков
```
