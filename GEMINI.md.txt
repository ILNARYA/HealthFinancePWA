# Правила проекта: Health & Medical Finance PWA

## Стек технологий
- Фреймворк: React + Vite + TypeScript (или Next.js).
- Стили: Tailwind CSS + Lucide Icons.
- PWA: vite-plugin-pwa (обязательны manifest.json, иконки и офлайн-кэширование).
- Графики: Recharts или Chart.js для визуализации показателей здоровья и трат.
- Интеграции: Google Sheets API (хранение записей о тратах и показателях), Google Drive / Photos API (загрузка сканов анализов).

## Требования к ИИ-модулю анализов
- При загрузке PDF или фото анализа извлекать ключевые биомаркеры, сравнивать с референсными значениями и формировать сводку.
- Обязательно добавлять дисклеймер: анализ носит информационный характер и не заменяет консультацию врача.

## Правила работы агента
1. Перед написанием кода всегда сначала создавай/обновляй план в файле `PLAN.md`.
2. После изменений запускай dev-сервер и проверяй интерфейс через встроенный браузер в мобильном разрешении (390x844).
3. Все секретные ключи (API Keys, OAuth Client ID) выносить строго в `.env` и добавлять в `.gitignore`.
